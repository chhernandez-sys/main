Proyecto de consola C# - Hola Mundo

Instrucciones para ejecutar (Windows):

1. Abrir PowerShell o CMD.
2. Ir al directorio del proyecto:

```powershell
cd C:\repos\main\HolaMundo
```

3. Ejecutar con dotnet:

```powershell
dotnet run
```

Si quieres compilar sin ejecutar:

```powershell
dotnet build
```

Nota: necesitas tener instalado el SDK de .NET (por ejemplo .NET 7). Comprueba la instalación con:

```powershell
dotnet --version
```
